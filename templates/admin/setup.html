Where to get these

Email with Gmail (free, about 5 minutes)

Use a Gmail account you’ll send from. Turn on 2-Step Verification in your Google Account → Security, then search “App passwords”, create one called {{ cfg.BRAND }}, and copy the 16-letter password. Here: server smtp.gmail.com, port 587, username = the Gmail address, password = the app password. Gmail allows about 500 emails a day — plenty to start.

Text messages with Twilio (about $0.10–0.15 a text)

Sign up at twilio.com, add about $20 credit, and buy a number that can send SMS to New Zealand. From the Twilio console copy the Account SID and Auth Token, and the number in +64 format (or the number Twilio gives you). Until the account is upgraded from trial, it can only text numbers you’ve verified in Twilio.

The describe helper (an Anthropic API key)

Create a key at console.anthropic.com → API keys and add a little credit. Each “help me describe it” costs roughly a cent or two.

Your own web address

Buy the name (e.g. through GoDaddy), add it in Render under the level service → Settings → Custom Domains, then add the DNS records Render shows you at GoDaddy. Once it’s working, put the full address here, like https://level.co.nz.

Will the emails arrive?

Before the first outreach run, check the emails won’t land in spam — and send yourself a real one to be sure.
